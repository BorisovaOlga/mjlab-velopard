# Flex model 8000: вид сбоку

- `rollout.mp4`: 6 секунд, 1920×1080, 50 кадров/с.
- `cycle.mp4`: цикл 3.16–3.62 с (0.46 с).
- `frame_01.png`–`frame_08.png`: исходные кадры Full HD.
- `cycle_sequence.png`: последовательность из 8 кадров, единое увеличенное поле обзора.
- `cycle.json`: номера кадров, время и checkpoint.
- `rollout_data.npz`: синхронные данные симуляции.

Камера: азимут 90°, возвышение 0°, следует за роботом.
Цикл выбран между касаниями передней левой лапы с проверкой повторения
положений суставов (RMS разницы 0.046 рад); краткие повторные контакты
внутри шага не использованы как границы цикла.
